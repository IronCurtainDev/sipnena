# 002: D1 and Drizzle

Use D1 for relational data and Drizzle for typed queries, schema, and migrations. Use indexes and small cursor-paginated application lists. Do not design around interactive SQL transactions: Better Auth's adapter disables them for D1.

The checked-in initial migration is for new databases. After deployment, schema changes are additive migrations; do not edit already-applied SQL. Multi-step operations need explicit recovery or compensation. See [operations](../operations.md).
