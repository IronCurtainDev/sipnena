# SipNena design system

Student/parent LMS for Sri Lanka (grades 6–11). Clean light blue UI.

## Brand

- Name: SipNena
- Primary: #0D5BD7
- Page backgrounds: #F8FAFC / #F4F7FB
- Surfaces: white cards, soft slate borders
- Trust: emerald accents for safety/curriculum cues

## Audience UX

- Plain language for students and parents (si / ta / en)
- Large tap targets (min ~48px CTAs)
- Calm motion; honor prefers-reduced-motion
- One clear primary action per screen

## Typography

- UI: Noto Sans family with Sinhala/Tamil coverage (self-hosted)
- Headings: bold, tight tracking; body: relaxed slate-600

## Components

- Full-bleed onboarding shell (header + language switcher + footer)
- Language radio cards; auth split panel (highlight + form)
